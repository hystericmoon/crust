Linked sections

Make a section once (a contact strip, a call to action), use it on many pages, and edit it in one place. Every page that uses it updates. Unlinking turns one back into a normal copy. Two ways to edit it:

Trade-offs

A · Recommended

Its own editor

  • You can't change four pages by accident while tidying one.
  • Saving says exactly what it does: “Save for all 4 pages”.
  • Keyboard and screen readers: one clear button, one clear screen.
  • One extra step to see the change in the page around it.
B

Edit in place

  • Quickest: change it where you see it.
  • Easy to forget it's shared; a typo fix for one page lands on all of them.
  • Undo and Save draft mix page edits with shared edits.
  • Harder to build reliably on top of the page builder.

Making and using one

Make

“Make linked” on a section

Next to “Save as layout” on the selected section's toolbar. Give it a name; the section on this page becomes the linked one.

Use

Layouts → Linked sections

A tab in the layout gallery lists your linked sections with a preview and how many pages use each. Insert adds it as a link, not a copy.

Unlink

A normal copy again

On one page only. The blocks stay as they are and become editable there; the other pages keep the link.

Delete

Only when unused

A linked section can be deleted once no page uses it. Until then the list names the pages, so nothing breaks on the live site.

Headings

No page title inside

A linked section can't hold the page's main heading (h1), because every page has its own. An h1 becomes an h2 when you make it linked.

Publishing

Plain HTML, as always

Each page is published with the section's current content built in. Renaming a page updates links inside linked sections too.

How it's saved

The section lives once in its own file; pages hold a small block that points to it.

content/sections/contact-strip.json
{ "id": "contact-strip", "name": "Contact strip", "savedAt": "…",
  "content": [ { "type": "Section", "props": { … } } ] }

In a page:
{ "type": "LinkedSection", "props": { "id": "LinkedSection-…", "section": "contact-strip" } }
