F062 · Milestone 6 · design snapshot

Premium templates in the gallery

Start from a template shows the free starters today. With F062 it also shows the premium templates from the Crust store: a preview at desktop, tablet and phone width, the price, and a “Get this template” button that opens the store in the browser. Without internet, only the free starters show.

The premium files aren't on the computer until someone buys one, so their preview is made of pictures from the store's catalogue, not the live template. A bought file opens with “Open a template file…”, as any .crust file does today. Template names and prices below are examples: the real ones come with Milestone 7.

Why A

No surprise prices

Free and paid are separate groups with plain labels, so the cost is known before a click. Surprises at the last step feel like a trap and cost trust (Nielsen: match with the real world, error prevention).

The same preview as today

A premium card opens the same screen as a free one: page list on the left, Desktop / Tablet / Phone on top. People learn it once (consistency). Only the button differs.

Free comes first

The gallery's main job is still starting a site now. The free starters stay at the top; premium is a clear second group, not an advert in the way.

Leaving the app is announced

“Get this template” says it opens the store in your browser, and the arrow shows it. Opening another app shouldn't happen unannounced (WCAG 3.2.2, change on request).

Keyboard and screen readers

  • Each group is a labelled region (“Free templates”, “Premium templates”); cards keep today's tab order, free first.
  • The price is text in the card's name for screen readers: “Olive, premium, US$49”. Never shown by colour alone.
  • “Get this template · US$49” carries “(opens in your browser)” for screen readers; the arrow is hidden from them.
  • Each preview picture has a description from the catalogue (“Olive home page at desktop width”); a picture without one isn't shown.
  • Price chips: dark text on white, 4.5:1 or more in both themes; buttons stay 44 px tall.

Left out on purpose

  • Buying inside the app. The store does that (Milestone 7); the app only opens its page.
  • Remembering what you bought. A bought template is a file; open it like any other.
  • Premium on the web admin's gallery too? Yes, same gallery code; it simply shows what the catalogue lists. Until the store exists (F063), no catalogue, so nothing extra shows anywhere.
