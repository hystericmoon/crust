Style customizer

Site settings grow into a full style customizer: type scale, heading weight and spacing, button shape and fill, card style, link style, and 9 complete presets. The controls below work. Pick how they're arranged.

Site settings

A · Grouped panel

  • One topic at a time: short, calm panel
  • Preview always in view while you change things
  • Grows cleanly as F031/F033 add groups
  • You don't see every setting at once

B · One long page

  • Everything on one scroll, like today
  • Easy to scan for "what did I change?"
  • Long already; 4 new groups make it very long
  • The control you're changing scrolls away from its preview spot

C · Preview first

  • Direct: click the thing you want to change
  • Biggest preview
  • Settings with no visible element (spacing, page width) need another way in
  • Harder to discover what's adjustable; weaker for keyboard users
Why A

Less to read at once. Showing one group at a time (progressive disclosure) keeps the panel short even with four new groups. Fewer visible choices make each decision faster (Hick's law).

The preview stays put. You change a button and watch the button, without scrolling away from it. A keeps C's best idea too: click a button in the preview and the Buttons group opens (it's how colours already work today).

Keyboard and screen readers: the group list is a plain list of links with the current one marked. Every option is a labelled radio group, so arrow keys work, as they do in the section styles today.

The same in every direction

Links always stay underlined. The three link styles differ in weight and tint, never "no underline". Colour alone can't mark a link (WCAG 1.4.1).

Presets set everything (colours, fonts, type, buttons, cards, links), and one Undo takes a preset back. The contrast badge at the top checks every colour pair live; a combination that fails offers a one-click fix, as now.

Nothing else changes: sites saved before F028 look exactly the same (Balanced scale, Bold headings, Rounded solid buttons, Flat cards, Underline links).

One question before building

"Main button" overlaps with section styles. Since F025 each section style already chooses its button look (Solid, Outline or Inverse). A second, site-wide fill would make two places that set the same thing.

Proposal: the Buttons group sets shape for every button. Its "Main button" switch edits the look of the Page and Muted styles together, where buttons are Solid today. Primary and Dark keep Inverse, which stays readable on a coloured background. "Soft" becomes a fourth look that section styles can use too. One setting, shown in two places, never two settings that disagree.
