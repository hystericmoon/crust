Columns that look designed, not just divided

New Columns options: boxes behind columns (colour, padding, corners), one highlighted column, vertical alignment, a separate gap between rows, dividers, photo-first on phones, and a column that stays in view while the other scrolls. Below: what each looks like on the page, then three ways to arrange them in the builder.

Rows of columns in a premium layout almost always share one look. Usually the only exception is one standout column (pricing, "most popular"). One look plus one highlight covers that in five controls, and rows stay consistent by default.

  • Consistency and standards: boxes reuse the site's section styles, so a column box matches a Muted section, and contrast is already checked.
  • Error prevention: "Photo first on phones" explains that reading order stays as written. Sticky offers only columns that exist, and only works on wide screens.
  • Gap and row gap stay in Advanced with spacing, as today.

Click a column on the canvas to select it, like Webflow or YOOtheme. It's familiar, but it changes the page format: every saved page with Columns would need a migration. It also adds a click level between the row and its blocks, which makes selecting a heading inside a column fiddlier.

Details

How it works

Saved as
New optional Columns props: valign, box { style, padding, rounded }, highlight { column, style }, rowGap, dividers, phoneOrder, sticky. A row without them publishes exactly as before, so no migration is needed.
Reading order
Never changed: "Photo first on phones" only moves columns visually, on phones. The builder notes it when the moved column holds links or buttons, because the Tab key would then jump back up (WCAG 2.4.3).
Sticky
From 1024 px wide, leaving room for a sticky header. A section that hid overflow would stop sticky from working, so sections switch to a clip that looks the same.
Dividers
Vertical between side-by-side columns, horizontal when they stack, worked out for each screen size from the widths you chose. Where columns wrap 2 + 1, no lines are drawn, because a half-row line looks broken.
