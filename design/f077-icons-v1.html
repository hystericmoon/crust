Icons that belong to the site, not clip art

An Icon block, icons in lists, cards and buttons, a Divider block, and a Social links block. Icons are drawn into the page as plain SVG when it's published: no icon font, no extra download, and they take the text colour, so contrast is checked like words.

The icon set

Lucide for everything, Tabler for brands

Lucide (ISC licence): a curated 120

Lucide has over 2,000 icons. Crust offers about 120 that business sites actually use: contact, places, time, food, services, shapes and arrows. A long list is hard to browse, and a small set keeps sites consistent.

Tabler (MIT licence): 16 social networks

Lucide removed brand logos in version 1, so the social icons come from Tabler Icons, drawn in the same 2 px line style. Both licences are on the allowed list in CLAUDE.md.

In the builder · picking an icon

Three directions

Recommended

A · Search plus categories, from the curated 120

Search icons: “phone”, “food”…
AllContactPlacesFoodServicesArrows

Truck · picked. Arrow keys move, Enter picks. Each icon has a spoken name.

  • Find by meaning: search matches synonyms ("food" finds utensils, coffee and pizza), so you don't need the icon's technical name (recognition over recall).
  • Small enough to browse: about 120 icons in six categories. Choice overload is real (Hick's law), and a tight set keeps a site's icons consistent.
  • Keyboard and screen reader: a grid of radio buttons with arrow keys, the same pattern as the other pickers in Crust.
  • Adding icons later is easy: they're one list in the code.

B · All 2,000+ Lucide icons, search only

Search 2,292 icons…

Results appear as you type; nothing to browse.

  • Everything is there, including very specific icons.
  • Search-only fails when you don't know the word, and many icons are near-duplicates (seven kinds of arrow). The builder also gets ~500 KB heavier.

C · No Icon block; icons only inside lists, cards and buttons

The Icon list keeps its own small set; Card and Button get an icon field.

  • Less to learn.
  • No "three features" rows with big icons, one of the most common premium patterns. You'd have to fake it with cards.

Accessibility

Decorative by default
An icon next to words is hidden from screen readers (aria-hidden), so nothing is read twice.
Meaningful when alone
An icon that is a link, or stands alone with no words, needs a name, and Crust asks for one (WCAG 1.1.1, 4.1.2).
Contrast
Icons use the text or primary colour of their section style, checked at 3:1 for graphics (WCAG 1.4.11). The badge circle uses the button colours, which are already checked.
Targets
Social links are at least 44 × 44 px with a visible focus ring.
