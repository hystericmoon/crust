F029 · Design snapshot v1

Per-device columns

Columns get a width for each device (for example two-thirds and one-third on desktop, stacked on a phone), and any block can be hidden on phone, tablet or desktop. The published site does it with plain CSS, no JavaScript. The controls below work. Pick how you set them.

Try with

A · All devices at once

  • See and change every device in one place
  • No hidden mode: what you see is what's set
  • Three rows of tiles: a longer panel

B · Follows the canvas

  • Short panel, matches the preview you're looking at
  • Easy to change Phone while thinking you're on Desktop
  • You can't compare devices without switching

C · Drag on the canvas

  • Direct and quick for odd widths
  • Small target on a zoomed-out canvas
  • Needs a separate way to stack on phones and to hide blocks
Why A

No mode errors. In B the same tiles mean different things depending on a switch somewhere else on screen, which is the classic way to change the wrong thing. In A each row says which device it's for. Seeing all three at once also shows you the whole result (visibility of system status).

Short anyway: the tiles are small, and the Phone row usually stays on "Stacked". The device names are links that switch the canvas preview, so you can check each one.

The same in every direction

Widths are fixed fractions (halves, thirds, quarters), not free numbers, so pages stay tidy and the published CSS stays small.

"Show on" for any block: Desktop, Tablet and Phone toggles (in F030's Advanced tab). In the builder a hidden block stays visible but faded and striped with "Hidden on phone", so you can still select it. On the published site it's left out for that device, for screen readers too.

Old pages don't change: today's behaviour (equal widths, 2 per row on tablet, stacked on phone) becomes the default.
