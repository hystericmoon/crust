# Harbour photos (F052)

Where each photo in the Harbour template came from. Every one is public
domain (CC0 1.0): it can be sold inside a template and needs no credit on
the site. This list is our own record, so we can show a photo's source
and licence if ever asked; it never ships in the template.

- Wikimedia Commons: each file's page shows its licence. Files marked
  "Unsplash, pre-2017" were first published on Unsplash while Unsplash
  released photos as CC0 (before June 2017); a CC0 dedication can't be
  withdrawn.
- NegativeSpace (https://negativespace.co/license/) and Skitterphoto
  (https://skitterphoto.com/license) publish everything under CC0.
  NegativeSpace doesn't name a photographer for every file, so the
  original file address is the record.

Cropped and resized here (at most 1920 px), metadata stripped.
Chosen by the owner on 2026-10-31 (design snapshot direction A, photo
picks https://claude.ai/artifact/2hkW4FDzmjPcXuzjYG4FYS).
